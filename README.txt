越南冒險日記｜原資料恢復版
1. 請將 ZIP 解壓縮到一個新資料夾。
2. 所有檔案請放在同一資料夾內。
3. 雙擊 index.html 使用 Chrome 或 Edge 開啟。
4. 此版本保留原本的六天行程、地點資料、離線常用句、成就、離線與出發檢查、互動地圖、日記及支出功能。
5. 地圖打卡及部分導航/自由翻譯功能需要瀏覽器允許相關功能或網路。
6. 請勿只單獨移動 index.html，否則圖片會無法顯示。

最新介面調整：
- 底部新增獨立「🎒 戰利品」選單，集中放置冒險小隊、戰利品背包與收藏圖鑑。
- 地圖只留在首頁，下方選單已移除「地圖」。
- 原有日記、照片、行程、支出、成就與備份還原功能保留。

旅費與預算功能：
- 在「旅費支出」頁設定旅程總預算（越南盾），按「保存預算」。
- 預算與支出使用不同的本機儲存鍵；既有支出紀錄不會因設定預算而清除。
- 每日支出與類別分布會依現有記帳資料計算。
- 請在更新前先使用「匯出完整備份（含日記與照片）」。本機資料不會因複製新版 HTML 自動搬移。

第五項新增：旅遊成就頁有冒險等級、總 EXP 與升級進度。經驗值由現有成就、行程打卡、景點探索及小隊 EXP 即時計算，不會另存重複獎勵。使用新版前仍建議先匯出完整備份。


離線使用補充（功能驗收修正版）：
- 已加入 service-worker.js，會快取首頁、樣式／程式所在的 HTML、圖示、封面與按鈕圖片等同源靜態資源。
- Service Worker 需要 HTTPS 或 localhost 等安全來源；直接雙擊 file:// 開啟時，瀏覽器不會啟用此離線快取。可使用本機靜態伺服器或 HTTPS 網站部署。
- 地圖、Google Maps 導航及線上翻譯仍需要網路；離線快取不會讓第三方服務變成離線可用。
- 更新或替換檔案前，請先匯出「完整備份（含日記與照片）」。本機資料通常存在原本瀏覽器的 localStorage／IndexedDB，複製新版檔案不會自動搬移資料。
- 驗收範圍：已進行 ZIP 完整性、JavaScript 語法、重複 HTML ID、內嵌按鈕函式引用與本地資源存在性檢查。此環境未安裝可啟動的 Playwright 瀏覽器，因此未宣稱完成真實瀏覽器端到端點擊測試。
